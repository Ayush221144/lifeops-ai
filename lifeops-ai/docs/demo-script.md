# Demo script (about 90 seconds)

1. Landing: "Your life has an API." Click **Try demo** (no login).
2. Dashboard: click **What should I do today?** and watch the stages, then the 3 ordered actions.
3. Open **Why HIGH?** on the electricity bill: deadline rule plus "unusual increase detected" (never a claimed cause).
4. Click graph nodes to show source document, deadline, recommendation and reason.
5. Click **Set reminder** on the warranty: read the approval dialog, then **Approve**. Show it under Upcoming.
6. Documents: **Try a sample bill** to show the analysis sequence.
7. If deployed: upload a real file and show the S3 object, DynamoDB item and `source: "model"` in the response.
